# AI-Assisted Decision Support System for Asteroid Search Processes

Merged clean version combining:

- **Seedless discovery pipeline**: difference imaging, star-residual rejection, tracklet linking and artefact filtering.
- **IASC criteria evaluation**: linear motion, constant velocity, brightness stability, SNR and shape.
- **RandomForest real/bogus ML model** (`realbogus_model.joblib`).
- **Astrometry**: RA/Dec, angular rate and position angle when WCS is available.
- **2024 WZ53 sample demo**: reproduces the original reference-guided blink, marked frames, motion trace and coordinate-change story.

## Important distinction

The **2024 WZ53 reference panel** uses known seed coordinates only to reproduce the sample demonstration. It does **not** feed seed positions into the discovery pipeline. The candidate list beneath it is generated by the seedless detector. If a seedless candidate matches the WZ53 reference trajectory, the interface labels that match; otherwise it explicitly says that no confident match was found.

## Performance changes

The old interface rendered candidate GIFs and plots for up to 30 candidates during every analysis. This version renders only the global blink plus the currently selected candidate, then lazily renders another candidate when selected. This substantially reduces unnecessary plotting work.

## Assets

To keep the GitHub mirror lightweight, the app uses local `frame1..4.fits` and `realbogus_model.joblib` when present; otherwise it fetches those public assets from the original Hugging Face Spaces on first use.
